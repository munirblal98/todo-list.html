# To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. This project helps users manage daily tasks by adding, completing, and deleting tasks dynamically.

Technologies Used:

HTML
CSS
JavaScript

Features:

Add new tasks
Mark tasks as completed
Delete tasks
Responsive user interface
Dynamic task handling using DOM manipulation

Purpose of the Project:

This project was created to practice JavaScript fundamentals, event handling, DOM manipulation, and responsive front-end development concepts.

What I Learned:

Working with JavaScript events
Manipulating HTML elements dynamically
Managing user input
Improving responsive UI design
Structuring small front-end projects

## Future Improvements

* Local storage support
* Task categories and priorities
* Dark mode
* Edit/update task functionality
